# Kit de experimentación y replicación - Grupo 2

Este paquete permite ejecutar y replicar el experimento controlado que compara:

- **Tratamiento A (control):** redacción libre de requisitos funcionales.
- **Tratamiento B (experimental):** redacción mediante plantilla estructurada y glosario de dominio.

## Orden de uso

1. Leer `02_Manual_Replicacion/MANUAL-REPLICACION-GRUPO2.pdf`.
2. Preparar consentimiento, encuesta y protocolo desde `03_Protocolo`.
3. Entregar a todos el caso común de `04_Materiales/CASO-ESTUDIO.pdf`.
4. Entregar únicamente la carpeta `Control` al grupo A y la carpeta `Experimental` al grupo B.
5. Evaluar los documentos anonimizados con `05_Evaluacion`.
6. Registrar los resultados en `06_Datos/plantilla_datos.csv`.
7. Ejecutar los scripts de `07_Analisis`.
8. Conservar la versión y registrar desviaciones en `09_Gestion`.

## Regla crítica

El grupo de control no debe acceder a la plantilla ni al glosario. Los evaluadores no deben conocer el tratamiento de cada documento durante la codificación inicial.
